# 一分钟演示脚本

## 录制前准备

1. 打开 PowerShell，并进入项目目录。
2. 把终端字体调大，关闭所有可能显示 `.env` 或 API Key 的窗口。
3. 提前运行一次下面的命令，确认 DeepSeek 账户可用。
4. 正式录制时使用 Windows 的 `Win + Alt + R`，或使用自己熟悉的录屏工具。

## 演示命令

```powershell
cd "E:\学习资料（绝密）\不要点开\SE\code-review-agent"
py -3 -m code_review_agent --workspace . --request "请先读取 examples/buggy_calculator.py，只报告最重要的三个问题，最终报告控制在 300 字以内。" --verbose
```

## 时间安排与讲解词

### 0–10 秒：介绍项目

> 大家好，我是计科2403班的干宸骅，学号2412190733。我的作业是一个基于 DeepSeek 的代码审查 Agent。

### 10–22 秒：说明架构

> 它不是简单调用一次模型，而是让模型根据任务自主选择目录扫描、文件读取和代码搜索工具。所有工具只允许访问指定工作区。

### 22–42 秒：运行命令

执行上面的命令。等待 DeepSeek 返回期间继续讲：

> 这里要求 Agent 先读取真实文件，再识别安全风险、异常处理和边界情况。程序还限制了文件大小、读取行数和最大循环次数。

### 42–55 秒：展示结果

把终端滚动到问题清单和最后的工具调用记录：

> DeepSeek 找出了 eval 任意代码执行、除零异常和裸 except，并给出了文件行号与修改建议。最后可以看到 Agent 实际调用过的工具。

### 55–60 秒：结束

> 项目包含会话记忆、接口重试、路径隔离和十一项自动化测试。演示完毕。

## 录制注意事项

- 视频必须控制在一分钟以内，建议最终成片为 50–58 秒。
- 不要打开 `.env`，不要展示 API Key、DeepSeek 账户余额或个人登录页面。
- 如果接口响应较慢，可以先录制一次成功运行，再剪掉等待时间，但不要剪掉命令和结果。
- 建议文件名使用 `2412190733干宸骅-演示.mp4`。
